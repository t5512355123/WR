5600 的結果顯著差於 5632 的 `HELPER_ERROR_MEAN=19250`，因此 5632 仍是目前
最佳 coarse 起點。這也顯示單純縮小 FDEC 數字不能取代正常 HPLL 細迴路；下一輪
應以 FDEC5632 為 bootstrap 基準，開啟 `ENABLE_NORMAL_HPLL_TRACKER`，觀察細迴路
是否能處理剩餘誤差。不能把本輪的 rail 或 lock counter 當成 Step5 pass，也不應
merge。
