# EXP-WRPC-STEP5-STATIC-COARSE-BRACKET-FDEC5440-20260908

## 結論

本輪完成 FDEC5440 的固定 coarse operating-point 實驗。兩次 preflight 都確認
Step1～4B PASS，1200-sample observer 因此有效；但 5440 比 5632 明顯偏離
最佳工作點，仍未進入 Helper lock band，Step5 未完成。

5440 的結果比 5632 的 `HELPER_ERROR_MEAN=19250` 更差，且 rail 比例再次偏向
低 rail；短暫的 lock counter 上升並未形成 `HELPER_LOCKED`，不能視為 lock。
目前最有價值的工作點仍是 5632 附近，下一輪應採用小步距（例如 5600 或
5664）做局部探測，不應再以 5440 作為零點，也不應宣稱 Step5 pass 或 merge。
