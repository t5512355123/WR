# Step1 candidate source relocation map

Historical source root: commit
`b8d4c3d0526f0c2ca282600ef06648dd9f0af595`.

The candidate keeps the historical Quartus revisions and design content, but
places the project in a root that can be copied into a frozen milestone
without relying on sibling directories from the main repository:

| Historical path | Candidate path |
|---|---|
| `quartus/jtag_runtime_diag/*` | `candidate_source/quartus/*` |
| `generated/work_wrphy_full/*` | `candidate_source/quartus_generated/work_wrphy_full/*` |
| `rtl/clock/si5340_controller/*` | `candidate_source/quartus/si5340_controller/*` |
| `firmware/*` | `candidate_source/firmware/*` |
| `vendor/*` | `candidate_source/vendor/*` |

The QSF changes are path-only:

```text
../../vendor/                         -> ../vendor/
../../generated/work_wrphy_full/     -> ../quartus_generated/work_wrphy_full/
../../rtl/clock/si5340_controller/    -> si5340_controller/
```

The two top-level VHDL files change only the firmware-MIF relative path:

```text
../../build/firmware/{master,slave}/wrc.mif
    -> ../build/firmware/{master,slave}/wrc.mif
```

Firmware is rebuilt inside the candidate root before Quartus compilation, so
the referenced `build/firmware/{master,slave}/wrc.mif` files are generated by
the included historical firmware scripts. No top-level entity, board pin,
clock, reset, RTL, firmware, or timing assignment is intentionally changed.

The path changes must be verified by a complete missing-file/path audit and
the independent clean builds; a textual path audit alone is not build proof.

## Cross-platform line endings

The Windows working tree initially had CRLF endings in 1,098 text files.
Those files were normalized to LF without changing any other bytes. Candidate
`.gitattributes` pins auto-detected text files to LF and explicitly protects
binary build formats. `candidate_source/SHA256SUMS` excludes itself, ignored
build outputs, and Python bytecode caches, so the source manifest can be
verified from the Linux Pain checkout as well as Windows.
